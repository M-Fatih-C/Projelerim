# Early Python and CAD learning archive

Two original archive snapshots preserve early learning work:

| Archive | Verified contents |
|---|---|
| `Python Scripts.zip` | 7 Python exercises: currency conversion, factorial, weather reminder, calculator, matrix addition, clock and data analysis |
| `Bilgisayar destekli tasarım.zip` | 20 AutoCAD DWG drawings |

## Inspecting the snapshots

Download only in an environment where you can inspect archived source before
running it. Python exercises can depend on historical GUI packages, web pages
or local data; the archive has no single dependency manifest or root test command.
DWG files require compatible CAD software. No modern runtime/build guarantee is made.

The audit read the ZIP member lists and scanned text members for specific secret
patterns without extracting/reorganizing the originals. It did not run scripts,
open drawings in CAD, or inspect binary drawings through OCR. No pattern match is
not proof that all archived content is free of sensitive information.

## Historical context

This is an inactive learning archive. `early-programming-archive` contains related
but separately preserved source projects; a byte-for-byte comparison did not
establish identical Python members for these ZIPs. Semantic overlap remains a
review topic. No archive was merged, moved, deleted or rewritten. Newer projects
should be evaluated through their own repositories rather than this snapshot.
